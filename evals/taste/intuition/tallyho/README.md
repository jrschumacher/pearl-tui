# tallyho

A time tracker for freelancers: start a timer on a client's project, see the week's
entries, and turn a client's hours into an invoice. Synthetic fixture: every product,
client and brand in it is fictional.

## Brand
- Name: lowercase `tallyho`, always.
- Colours: plum `#A06CC9` (primary) and chalk `#E6DFD3` (secondary) on `#121014`.
- Logo: a tally of four strokes crossed by a fifth (describe it; there is no file).
- Voice: brisk, honest, tidy. Never a corporate timesheet.
