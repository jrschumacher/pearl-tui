# spoofify

Music streaming where every track is a spoof: made-up bands playing parodies of
made-up hits, and covers nobody asked for. Synthetic fixture for the taste rounds: every
product, band, track and label in it is fictional, including the "originals" each spoof
sends up.

`spoofify` is the terminal client. Listeners leave it open beside their work for hours,
glance at it to see what's playing, and drop in to search or queue a track.

## Usage

```
spoofify                     now playing, what's next, and search
spoofify play <query>        search and play the first match
```

## Brand

- Name: lowercase `spoofify`, always.
- Colours: sleeve heather `#B97AA8` (primary) and label cream `#E0C9A6` (secondary) on a
  late-night ink `#0D0B12`.
- Logo: a vinyl record wearing a fake moustache (describe it; there is no file).
- Voice: cheeky, nocturnal, deadpan; fond of the music it mocks.
