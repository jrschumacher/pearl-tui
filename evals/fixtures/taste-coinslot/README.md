# coinslot

A launcher for a collection of terminal arcade games: pick a cabinet, see the high
scores, press start. Synthetic fixture for the taste rounds: every product, game and
brand in it is fictional.

`coinslot` is the launcher. Players open it for an evening, browse the cabinets, check
who holds the high score, and launch one.

## Usage

```
coinslot                      the arcade floor
coinslot play <game>          launch a game
```

## Brand

- Name: lowercase `coinslot`, always.
- Colours: 1UP lime `#B5E550` (primary) and marquee lilac `#C9B6E4` (secondary) on an
  arcade dark `#0A0A12`.
- Logo: a coin dropping into a slot, mid-fall (describe it; there is no file).
- Voice: bright, generous, showy; it loves its players' scores.
