# lanternfish

An observability agent: it collects logs, metrics and traces from your services and
ships them to lanternfish cloud or to your own self-hosted collector. Synthetic fixture
for the taste rounds: every product, company and brand in it is fictional.

`lanternfish init` is the first-run setup every new user goes through once, on the
machine the agent will run on, often over SSH. It connects the agent to an account,
says where data goes and what to collect, and starts collecting. People want it done
and right: a wrong answer here means missing data later.

## Usage

```
lanternfish init           the first-run setup
lanternfish status         what the agent is collecting
```
