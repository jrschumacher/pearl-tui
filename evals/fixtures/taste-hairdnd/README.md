# hairdnd

Short-term rentals of tabletop-game dens for hairy people and their hairy dogs: a table
big enough for a campaign, dice towers, shed-safe sofas, lint rollers at every seat.
Synthetic fixture for the taste rounds: every product, place and brand in it is
fictional.

`hairdnd` is the terminal client for guests. A party's organiser uses it to find a den
for a weekend session, compare a few, and book one.

## Usage

```
hairdnd                       search dens
hairdnd search <town>         dens in a town
```

## Brand

- Name: lowercase `hairdnd`, always.
- Colours: tavern amber `#D98E32` (primary) and lichen `#5E7D4B` (secondary) on a
  candlelit dark `#16120E`. Light terminals: the same hues on `#F7F1E6`.
- Logo: a twenty-sided die asleep on a shaggy hearth rug (describe it; there is no file).
- Voice: warm, shaggy, adventurous, like a good game master.
