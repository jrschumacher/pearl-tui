# bisque

Continuous integration that fires your builds: pipelines of steps that run on every
push. Synthetic fixture for the taste rounds: every product, repo and brand in it is
fictional.

`bisque` is the terminal client. Engineers run it right after a push to watch their
pipeline, read why a step failed, and retry or cancel it.

## Usage

```
bisque                        recent runs for this repo
bisque watch [run]            follow a run live
```

## Brand

- Name: lowercase `bisque`, always (the first firing a pot goes through).
- Colours: one hue, ember `#E4572E`, on fired-clay dark `#141210`. Ember means a step
  that is firing (running), nothing else.
- Logo: a kiln's arched mouth with a flame inside (describe it; there is no file).
- Voice: hot, terse, workmanlike; says what broke and where, in one line.
